# The secret scan's pattern list (tools/secret_scan.py): one per line, "name<TAB>regular expression" (Python's re). A hit anywhere in the tree fails
# tools/ci.sh. Written by hand from the providers' documented key shapes; no scanner package is needed (brief J2: a scanner would be a dependency).
# A line in a file that must hold such a shape on purpose (the tests' made-up passwords) carries the words "secret-scan: allow" and is skipped.
# The last two are generic (brief J2 verification S2): a long token or key literal assigned to a name that says it is one, and any password literal.
#
# Real clients' names are not listed here: the scanner holds only their hashes (a list of names would itself be real people's information in git).
private_key	-----BEGIN (?:RSA |DSA |EC |OPENSSH |ENCRYPTED |PGP )?PRIVATE KEY(?: BLOCK)?-----
twilio_account_sid	\bAC[0-9a-f]{32}\b
twilio_api_key	\bSK[0-9a-f]{32}\b
twilio_auth_token	(?i)twilio\w*(?:auth|token)\w*\s*[=:]\s*["']?[0-9a-f]{32}\b
google_oauth_client_secret	\bGOCSPX-[A-Za-z0-9_-]{28}\b
google_api_key	\bAIza[0-9A-Za-z_-]{35}\b
google_service_account_key	"private_key_id"\s*:\s*"[0-9a-f]{40}"
microsoft_client_secret	(?<![A-Za-z0-9_~.-])[A-Za-z0-9_~.-]{3}\dQ~[A-Za-z0-9_~.-]{31,34}(?![A-Za-z0-9_~.-])
aws_access_key	\b(?:AKIA|ASIA)[0-9A-Z]{16}\b
github_token	\b(?:gh[pousr]_[A-Za-z0-9]{36,}|github_pat_[A-Za-z0-9_]{60,})\b
slack_token	\bxox[abprs]-[A-Za-z0-9-]{10,}
stripe_live_key	\b(?:sk|rk)_live_[0-9A-Za-z]{24,}\b
sendgrid_api_key	\bSG\.[A-Za-z0-9_-]{22}\.[A-Za-z0-9_-]{43}\b
fernet_key_in_settings	(?i)(?:I485_TOTP_KEY|CLIO_TOKEN_KEY|FERNET_KEY)\s*[=:]\s*["']?[A-Za-z0-9_-]{43}=
oauth_secret_assigned	(?i)\b(?:client_secret|clientsecret|auth_token|smtp_password)\s*[=:]\s*["'][A-Za-z0-9_~.+/=-]{20,}["']
generic_token_assigned	(?i)(?<![\w.-])[\w.-]*(?:token|secret|passwd|password|api_?key|apikey|private_?key|_key)\s*[=:]\s*["'][A-Za-z0-9+/_=-]{32,}["']
password_literal	(?i)\b(?:password|passwd|pwd)\s*[=:]\s*["'][^"'\n]{4,}["']
